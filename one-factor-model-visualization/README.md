# Однофакторная модель: визуализация

Интерактивная пошаговая визуализация однофакторной модели

$$Y_{it} = c_i + \ell_i\, X_{it}^\top \beta + u_{it},\qquad i = 1,\dots,n,\quad t = 1,\dots,T.$$

Пять шагов на синтетических данных (8 магазинов, признаки «скидка» и «реклама»):

1. **Данные** — панель «магазины × недели».
2. **Каждый сам за себя** — отдельная регрессия для каждого магазина, наклон рисуется стрелкой.
3. **Одна стрелка** — по модели все наклоны лежат на одной прямой $\operatorname{span}(\beta)$: $b_i = \ell_i \beta$.
4. **Что можно узнать** — неидентифицируемость масштаба ($\beta \to a\beta$, $\ell_i \to \ell_i / a$), влияние шума и числа наблюдений $T$.
5. **Сжатие и общая прямая** — сводные статистики $(Z_i, \widehat G_i)$, эллипсы неопределённости наклонов и подбор общего направления $\beta$.

Всё работает в браузере, без установки. Вся страница — один файл `index.html` без зависимостей (шрифты подгружаются из Google Fonts, без интернета используются системные).
