# Многофакторная модель: визуализация

Интерактивная пошаговая визуализация многофакторной (многоиндексной) модели панельных данных

$$Y_{it} = c_i + X_{it}^\top \bigl(\ell_{i1}\beta_1 + \dots + \ell_{im}\beta_m\bigr) + u_{it},\qquad X_{it} \in \mathbb{R}^{100}.$$

Пять шагов на синтетических данных (12 магазинов, 100 признаков, два общих индекса):

1. **Реакции магазинов** — профили из 100 наклонов и тепловая карта «магазины × признаки».
2. **Всё в одной плоскости** — истинные наклоны $b_i = \ell_{i1}\beta_1 + \ell_{i2}\beta_2$ лежат в двумерной плоскости 100-мерного пространства; вращаемая проекция на три направления.
3. **Два образца и нагрузки** — профиль магазина раскладывается на $\ell_{i1}\beta_1 + \ell_{i2}\beta_2$; вместо $12 \times 100 = 1200$ параметров остаётся 224.
4. **Что можно узнать** — базис $(\beta_1, \beta_2)$ определён только с точностью до поворота внутри плоскости; выбор главных осей.
5. **Поиск плоскости** — SVD матрицы наклонов $12 \times 100$, выбор числа индексов $m$, угол между найденной и истинной плоскостью.

Вся страница — один файл `index.html`, работает в браузере без установки.
