Панельная лаборатория

Здесь можно покрутить многоиндексную модель панельных данных с латентными факторами. Страница генерирует синтетическую панель по модели, оценивает её нашим алгоритмом и конкурентами и показывает, кто ближе к правде. Истинные наклоны в синтетике известны, поэтому ошибку можно посчитать честно.

Ошибка наклонов

Ошибка = ‖B̂ − B‖ / ‖B‖, где B — матрица истинных наклонов всех индивидов. 0,1 значит, что наклоны в среднем ошибаются на 10% своей величины. Прочерк — метод здесь невозможен: на индивида меньше наблюдений, чем параметров.

Наклоны и плоскость индексов

МНК с фактораминаша модель

Каждая точка — один индивид. По горизонтали — его наклон вдоль первого индекса, по вертикали — насколько наклон торчит из подпространства индексов. У истинных наклонов вертикаль равна нулю. МНК по каждому индивиду размазан шумом вверх, наша модель прижата к плоскости, потому что знает, что наклоны лежат в ней.

Строки — индивиды, столбцы — моменты времени, цвет — значение. Во вкладке «факторная часть» видны вертикальные полосы: общий шок бьёт по всем индивидам в один момент, но с разной силой. Именно эти полосы алгоритм вычищает проекцией.

Как сходится алгоритм

Ошибка наклонов на каждой итерации. Точка 0 — старт: факторы по главным компонентам всей панели и МНК по каждому индивиду. Дальше чередуются два шага: наклоны с малым рангом при текущих факторах и факторы по остаткам. Пунктир — оракул. Обычно хватает нескольких итераций, чтобы до него дойти.

Эксперимент: меняем один параметр

Данные синтетические: индексы — гладкие профили по признакам, факторы — процессы AR(1), признаки связаны с факторами через случайные нагрузки, шум гауссовский. Всё считается в браузере. Метод и теоремы описаны в дипломе «Оценивание одноиндексных и многоиндексных моделей панельных данных с латентными факторами», М. Муравский, матфак ВШЭ.
