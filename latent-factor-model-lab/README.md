# Многоиндексная модель с латентными факторами: лаборатория

Интерактивная лаборатория для многоиндексной модели панельных данных с латентными факторами

$$Y_{it} = c_i + X_{it}^\top P^\top \ell_i + \gamma_i^\top f_t + \varepsilon_{it},\qquad b_i = P^\top \ell_i .$$

Страница генерирует синтетическую панель по модели и прямо в браузере оценивает её предложенным алгоритмом (проекционный шаг по наклонам и главные компоненты остатков для факторов) и конкурентами. Истинные наклоны известны, поэтому ошибку $\|\hat{\mathcal B} - \mathcal B\|_F / \|\mathcal B\|_F$ можно посчитать честно.

Что можно делать:

1. **Менять данные** ползунками: число индивидов $n$, длина ряда $T$, число признаков $d$, индексов $m$ и факторов $r$, сила связи признаков с факторами и шум $\sigma$.
2. **Менять то, что знает алгоритм**: сколько индексов и факторов он берёт (например, специально недооценить $r$).
3. **Сценарии**: короткие ряды, признаков больше, чем наблюдений ($T < d$), сильные факторы, факторы безвредны, мало индивидов, недооценённые факторы.
4. **Смотреть результаты**:
   - ошибка наклонов пяти методов: МНК по каждому индивиду без факторов и с факторами, малый ранг без факторов, наша модель, оракул (истинные факторы подсказаны);
   - облако наклонов относительно подпространства индексов;
   - тепловая карта панели: отклик, факторная часть $\gamma_i^\top f_t$, шум;
   - ошибка наклонов по итерациям алгоритма.
5. **Эксперимент**: кривые ошибки в зависимости от $T$, $n$, силы связи с факторами или $d$.

Вся страница — один файл `index.html`, работает в браузере без установки (шрифты подгружаются из Google Fonts, без интернета используются системные).
