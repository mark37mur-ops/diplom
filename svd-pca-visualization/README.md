# SVD и PCA: визуализация

Интерактивная пошаговая визуализация сингулярного разложения и метода главных компонент

$$A = U\Sigma V^\top = \sum_k \sigma_k u_k v_k^\top.$$

Пять шагов:

1. **Поворот и растяжение** — матрица $2 \times 2$ как поворот $V^\top$, растяжение $\Sigma$ и поворот $U$; единичная окружность переходит в эллипс с полуосями $\sigma_1 u_1$, $\sigma_2 u_2$.
2. **Сумма слоёв** — малоранговое приближение $A_k$ (теорема Эккарта–Янга) на картинке $64 \times 64$, таблице оценок фильмов и матрице «сигнал ранга 3 + шум».
3. **Главная ось** — PCA на облаке оценок: максимум разброса проекций совпадает с минимумом остатков.
4. **Центрирование** — PCA через SVD центрированной матрицы, что меняется без центрирования, влияние выброса.
5. **Сколько компонент** — облако в $\mathbb{R}^3$, доля объяснённой дисперсии и сингулярные числа матрицы наклонов $12 \times 100$ из многофакторной модели.

Вся страница — один файл `index.html`, работает в браузере без установки.
